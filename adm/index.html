Falta ligar a publicação pelo celular. É uma vez só, no PC:

1. No GitHub (Settings → Developer settings → Fine-grained tokens), crie um token com acesso aos repositórios v9-flow (Actions: leitura e escrita; Contents: leitura), Oraclemovie, v9flow-dist e v9vision-dist (Contents: leitura).

2. No Supabase (Edge Functions → Secrets), crie o segredo GITHUB_PUBLICAR_TOKEN e cole o token lá. Nunca mande o token por mensagem.

O GitHub não respondeu. Confira se o token ainda vale e tem as permissões acima.
